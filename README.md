# WinTune

WinTune is an early-stage Modern C++ project exploring Windows optimisation and system configuration through a simple, safer interface.

The project currently focuses on reading and modifying selected Windows Registry settings, with support for displaying current values, descriptions, recommended settings, and basic risk information before changes are applied.

## Current Features

* Win32 Registry read/write functionality
* Error handling and data-type validation
* Safe registry handle management
* Basic command-line interface for viewing and applying tweaks

## Planned

Future areas may include:

* Windows power plan configuration
* Device power-saving settings
* CPU scheduling options
* Windows services
* Restore point creation
* Per-setting rollback

## Project Status

This is currently a **very early-stage, low-priority passion project** that I work on alongside other projects and commitments.

It is mainly a way for me to explore Windows internals, Modern C++, and safer approaches to system configuration, so the scope and implementation will continue to evolve over time.
